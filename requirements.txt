# Native OS trust-store bridge for stdlib ``ssl`` so corporate / Windows
# certificates work out of the box. Avoids ``CERTIFICATE_VERIFY_FAILED`` on
# ``api.openai.com`` when ``certifi`` lacks the user's local CA. Activated
# from ``app.py`` via ``truststore.inject_into_ssl()``; falls back silently
# on Python < 3.10 or unsupported platforms.

# Headless system-browser fallback for SPA career pages (Microsoft, Workday,
# Greenhouse). The Python package is small; we drive the user's existing
# Chrome / Edge installation through `channel="chrome"` / `channel="msedge"`,
# so `playwright install` is only needed if neither browser is present.

# Document parsing & generation

# AI_API_KEY / GITHUB_TOKEN encrypted at rest.
keyring~=25.4
